# Auto HDR Switch

Tray app that turns Windows HDR on when a Steam game launches from the Start Menu and off when it quits.

## Setup
```
pip install -r requirements.txt
pythonw hdr_enabler.py
```

Application can be accessed from the system tray.

## Usage
- Enable HDR for your selected games in the tray app
- Launch the game from the Start Menu (will not work if launched from Steam directly)
- When the game is closed, HDR will be turned off automatically
